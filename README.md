# Strecke Next

Built files of the Strecke **Next** channel (new features before they reach the stable app). Release `v0.2.0`, built from commit `dbe4911` of the `strecke` repository. Own storage namespace (`strecke-next`), own service-worker scope and cache prefix; it never reads or changes the stable app's data.

Deployed and rolled back with `tools/release.ts` (see `RELEASES.md` in the source repository). Every release is a tag here; nothing is ever force-pushed.
